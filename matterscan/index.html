Settings & training (optional)

Electronics — your own device model. Optional. Train a Teachable Machine image model on your devices and paste the link; when set it's used instead of MobileNet.

Plastics — your own code model. Optional. Train a model on the 7 resin symbols with classes named exactly 1–7; when set and the camera is on, the matching code is auto-highlighted.

Live answers (advanced, off by default). Optional. Paste an OpenAI-compatible API key to enable an "Ask about this item" button for open-ended disposal/upcycling advice on the detected item. Everything works without it — the demo never depends on it. Your key is stored only in this browser and sent only to the endpoint you set; it is never logged.

How it works (for the Q&A)

Electronics use computer vision: MobileNet, a neural network trained on millions of photos, recognises the device on your screen; a rule flags anything electronic as e-waste and shows baked guidance for it. Plastics are tap-first on purpose: the resin stamp is only 2–3 mm, so reading it from a webcam is unreliable — tapping the number gives accurate, trustworthy data every time. Both run on your device; nothing is uploaded.

The optional custom models use transfer learning: they reuse MobileNet's general image knowledge and only re-learn your specific classes, so ~30–50 photos per class is enough.
