Settings & training (optional)

Automate freshness with your own model. Train a Teachable Machine image model with classes named exactly fresh, spoiling, spoiled, export it as an uploaded shareable link, and paste it here. Until you do, the manual buttons work fine.

Live rescue ideas (advanced, off by default). Optional. Paste an OpenAI-compatible API key to enable a “Fresh idea” button that writes a tip for the exact item. Everything works without this — the demo does not depend on it. Your key is stored only in this browser and is never sent anywhere except the endpoint you set.

How it works (for the Q&A)

Three steps run on each camera frame, all on your device — nothing is uploaded. Identify: MobileNet, a neural network trained on millions of photos, names the produce (e.g. “banana”). Judge freshness: freshness can’t come from MobileNet — a banana is a banana whether ripe or rotten — so it comes either from your own Teachable Machine model (trained on fresh/spoiling/spoiled photos) or from the manual buttons. Advise: the item and its state are matched to a built-in rescue idea and storage tip.

The custom model uses transfer learning: it reuses MobileNet’s general understanding of images and only re-learns the fresh/spoiling/spoiled distinction, which is why ~30–50 photos per class is enough.
