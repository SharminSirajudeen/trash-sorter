How it works (for the Q&A)

A neural network called MobileNet runs entirely inside this browser — nothing is sent to a server. It was trained on millions of photos to recognise everyday objects. When it names what the camera sees (say, "water bottle"), a small rule matches that object to its correct waste stream and colours the panel with that bin's colour. So there are two steps: recognise the object, then map the object to a bin.

Limits worth admitting up front: it can only sort things it has seen before, it can confuse look-alikes (a glass and a plastic bottle), and poor light lowers its confidence. Those are honest boundaries of any vision model, not bugs.
