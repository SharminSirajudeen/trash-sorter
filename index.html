Use your own trash-trained model (recommended)

Train a free model on real waste photos in ~20 minutes, then paste its link here. The app will use it instead of the general model, so it's genuinely sorting trash, not guessing from object names.

  1. Go to teachablemachine.withgoogle.com → New Project → Standard image model.
  2. Make one class per bin and name them exactly: plastic, paper, metal, glass, organic, ewaste, trash. (Skip any you don't need.)
  3. Add 30–50 webcam photos to each class — different angles, lighting, backgrounds.
  4. Click Train Model, then Export → Upload (shareable link) and copy the URL.
  5. Paste it below and press Use my model.
How it works (for the Q&A)

A convolutional neural network runs entirely inside this browser — nothing is sent to a server. In general mode it uses MobileNet, trained on millions of everyday-object photos, and a rule maps the object it names to the right bin. In trash mode it uses your own model, trained on waste photos, so each class it predicts is a bin — no guessing step.

Honest limits: a model only knows what it was trained on, look-alikes (a glass vs a plastic bottle) can fool it, and poor light lowers confidence. Training your own model on your real items is what fixes most of this.
